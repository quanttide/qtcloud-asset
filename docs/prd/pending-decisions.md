## 一、访问链接有效期（原「待明确 1」）

**当前状态**：方向已定（2026-08-16 郝子腾确认），具体参数待周会确认默认值。

| 事项 | 已定方向 |
|------|---------|
| 链接有效期 | **灵活设定**：生成链接时根据场景指定（内部长期 / 客户 7 天 / 临时 24h 等），不写死单一有效期 |
| 用户自选有效期 | **要**：界面上提供有效期选择（如 1 天 / 7 天 / 永久），用户生成链接时自己选 |
| 链接生成方式 | 后端签名 URL（私密桶）；公开桶可直接公开 URL |

**待周会确认的默认值**：
1. 私密桶链接的「默认有效期」设多少（建议 24h）
2. 有效期选项档位（如「1 天 / 7 天 / 30 天 / 永久」是否够用）
3. 是否允许「永久」选项（永久 = 很长有效期，安全上需谨慎）

## 二、权限控制（原「待明确 2」）

**当前状态**：已确认 6 个私密桶 + terraform-state 桶均为 `private` ACL，外部无法直接访问。但「谁能看什么」的分级规则未定。

| 需拍板 | 选项 |
|--------|------|
| 角色分级 | A. 管理员/内部/普通 三级（黎想方案）/ B. 内部/外部 两级（更简单） |
| 私密桶可见范围 | A. 仅管理员+授权人员 / B. 全体内部人员 |
| 实训基地人员权限 | A. 仅访问公开资料 / B. 可访问内部资料 / C. 无任何访问 |
| 权限落地方式 | A. Studio 后端加登录鉴权 / B. 先不做鉴权，只靠桶 ACL 兜底 |

**建议**：先做「内部/外部」两级，Studio 后端加登录态，私密桶仅授权人员可见；实训基地人员仅公开资料。
