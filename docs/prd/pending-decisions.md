# 对象存储可视化 — 待拍板事项清单

> 用途：提交下周周会决议
> 起草人：郝子腾
> 起草日期：2026-08-16
> 关联：33 周会「对象存储可视化平台方案」决议 / `oss-integration.md`

## 背景

33 周会决议结论是「附议区一致支持，但需在启动前明确访问链接有效期、权限控制方案及项目落地要素」。截至 2026-08-16，技术侧已完成只读接入（桶列表、文件浏览、目录下钻、搜索排序）。

> **最新状态（2026-08-27）**：Plan A 后端门禁继续采用 `viewer` / `admin` 两级角色。`viewer` 隐藏 `-private` 桶和 `quanttide-terraform-state`，`admin` 可查看全部桶及私密桶对象元数据。私密桶和 `quanttide-terraform-state` 不生成访问链接；公开桶保留永久直链。

## 一、访问链接有效期（原「待明确 1」）

**当前状态**：公开桶使用永久直链；私密桶不提供对象访问链接。有效期选择不属于当前产品能力。

| 事项 | 已定方向 |
|------|---------|
| 链接有效期 | 公开桶为永久直链；私密桶不生成链接 |
| 用户自选有效期 | 当前不提供有效期选择 |
| 链接生成方式 | 公开桶返回直链；私密桶拒绝对象链接请求 |

**后续仍需确认**：
1. 未来如需访问私密对象，是否另行设计审批、代理访问和审计机制。

## 二、权限控制（原「待明确 2」）

**当前状态**：已确认 6 个私密桶 + terraform-state 桶均为 `private` ACL，外部无法直接访问。Plan A 已先落地两级可见性：`viewer` 看公开桶，`admin` 看全部桶。

| 需拍板 | 选项 |
|--------|------|
| 角色分级 | Plan A 临时落地为 `viewer` / `admin` 两级 |
| 私密桶可见范围 | `viewer` 桶清单隐藏；`admin` 可查看全部桶及对象元数据，但不能生成对象访问链接 |
| 实训基地人员权限 | A. 仅访问公开资料 / B. 可访问内部资料 / C. 无任何访问 |
| 权限落地方式 | A. Studio 后端加登录鉴权 / B. 先不做鉴权，只靠桶 ACL 兜底 |

**建议**：先做「内部/外部」两级，Studio 后端加登录态，私密桶仅授权人员可见；实训基地人员仅公开资料。
