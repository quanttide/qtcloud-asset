# 资产云页面使用说明

量潮资产云用于浏览对象存储桶和其中的文件。页面按账号权限展示可访问的内容。

## 登录页

在「登录资产云」页面输入账号和密码后，点击「登录」进入首页。登录状态失效时，页面会提示重新登录。

## 桶列表

首页显示可访问的对象存储桶。每张桶卡片标注桶名和用途分类。

- 点击分类标签，可筛选 Studio、Private、Site、Provider 或全部桶。
- 在搜索框输入桶名，可快速查找目标桶。
- 使用「创建时间」和「桶名」按钮调整排序方向，或关闭对应排序条件。
- 点击桶卡片进入对象浏览页。
- 桶较多时，使用列表底部的「上一页」和「下一页」查看其他桶。
- 右上角可刷新桶列表、查看我的分享或退出登录。

普通用户看不到私密桶和 Terraform 状态桶。管理员可进入这些桶查看对象元数据，但不能复制公开链接或创建分享。

## 对象浏览

进入桶后，页面列出当前目录下的文件和文件夹。

- 点击文件夹进入下一级目录，使用「返回上级」回到父目录。
- 在搜索框输入文件名或路径片段，可筛选当前列表。
- 使用「日期」和「大小」按钮调整文件排序。
- 对允许公开访问的文件，可复制公开链接。

私密桶只展示对象元数据，不支持公开链接或创建分享。

## 文件分享

在允许分享的桶中，可以分享一个文件夹，也可以进入「选择文件」模式后勾选多个文件和文件夹。

1. 选择要分享的内容，点击「分享」或「分享所选」。
2. 填写分享标题并创建链接。
3. 系统会自动复制分享链接，可直接发送给其他人。

点击首页右上角的「我的分享」可查看已创建的链接。该页面支持复制链接、刷新列表和撤销分享；撤销后，原链接会立即失效。

## 公开分享页

访问分享链接后，无需登录即可浏览被分享的文件夹和文件。

- 可进入下级文件夹，必要时返回上级目录。
- 单个文件可复制链接或直接下载。
- 点击「下载全部」可将分享内容打包为 ZIP 下载。

为避免浏览器处理过大的文件，分享内容总大小超过 100 MB 时，不能使用「下载全部」，需要分批下载。

## 用户管理

「用户管理」仅对管理员显示。管理员可以：

- 邀请新用户，并指定 `viewer` 或 `admin` 角色。
- 查看用户列表和当前角色。
- 修改用户角色。
- 停用账号。
- 撤销某个用户的现有登录会话。

## 常见提示

- 「没有匹配的桶」：请切换分类或清空桶名搜索。
- 「没有匹配的文件」：请清空或调整文件搜索。
- 「登录状态已失效」：返回登录页后重新登录。
- 「当前桶或文件不允许公开访问」：该资源不支持复制公开链接或创建分享。
